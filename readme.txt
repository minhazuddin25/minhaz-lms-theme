=== Minhaz LMS ===

Foundation theme for a learning website. Version 0.1.0.

This release intentionally contains no LMS, commerce, page-builder, custom post type, shortcode, analytics, caching, or demo-import functionality. Those capabilities belong in independently installable plugins.

Requirements: WordPress 6.6 or later, PHP 7.4 or later.

Translations: use the minhaz-lms text domain. Generate the POT file for each release from the source files.
